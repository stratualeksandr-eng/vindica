# Верни себя себе

Дневник стоика, план с напоминаниями и тренировки с гирей. Один и тот же код работает в трёх видах:

| Где | Что это | Напоминания |
|---|---|---|
| Сайт (GitHub Pages) | `index.html` в корне; на iPhone и iPad — Safari → Поделиться → «На экран „Домой“» | пока страница открыта |
| **Android** (телефон и планшет) | приложение `Vindica.apk` | **всегда**: время каждого дела ставится в сам телефон, уведомление приходит и при закрытом приложении |
| Windows / Linux / macOS | программа `Vindica-Setup-….exe` и др. | всегда, пока компьютер включён: программа живёт в трее и запускается вместе с системой |

## Синхронизация между устройствами
Записи одинаковые на всех устройствах, если они хранятся в твоём **закрытом** репозитории GitHub (отдельном от этого).
1. На github.com создай новый репозиторий, например `vindica-data`, и выбери **Private**.
2. Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token:
   Expiration — No expiration; Repository access — **Only select repositories** → `vindica-data`;
   Permissions → Repository permissions → **Contents: Read and write**. Скопируй ключ (`github_pat_…`).
3. В приложении: Настройки → «Синхронизация» → имя репозитория (`имя/vindica-data`) и ключ → «Подключить».
   То же на каждом устройстве. Записи, которые уже были на устройстве, сливаются с общими.

Без сети всё пишется как обычно и уходит, когда связь вернётся. Каждый документ — отдельный файл
(`plan/2026-11-23.json`, `days/…`, `ideas/…`), его можно читать и править; как — написано в `README.md` того репозитория.
Чтобы Claude в чате видел и менял записи, подключи GitHub к Claude в настройках Claude.

## Наставник (Claude) в приложении
В версии внутри Claude Наставник работает сам. В приложении, программе и на сайте — по ключу Claude API:
Claude Console (platform.claude.com) → Billing (пополнить баланс) → API Keys → Create Key;
в приложении: Настройки → «Claude для Наставника» → вставить ключ. Оплата отдельно от подписки, по факту использования.
Ключ хранится только на этом устройстве.

## Как получить приложение

После каждой загрузки файлов в репозиторий GitHub сам собирает приложения (вкладка **Actions**, около 10 минут).
Готовые файлы — в разделе **Releases**. Самая свежая сборка всегда здесь:
`https://github.com/<имя>/<репозиторий>/releases/latest`

### Android
1. Открой ссылку выше на телефоне, скачай `Vindica.apk`, открой файл и разреши установку.
   На Samsung, если установка заблокирована: Настройки → Безопасность → **Автоблокировщик** — выключить.
2. При первом запуске разреши уведомления и микрофон (для диктовки).
3. Чтобы Samsung не усыплял напоминания: Настройки → Обслуживание устройства → Батарея →
   Ограничения фонового использования → **Приложения, которые никогда не уходят в сон** → добавить «Верни себя себе».
4. Записи с сайта переносятся через Настройки → «Перенос данных»: скопировать там, вставить здесь.

Новая версия ставится поверх старой, записи сохраняются. Для этого все сборки подписаны одним ключом
`android/vindica.keystore` (пароль в `android/keystore.properties`). Не удаляй и не меняй эти два файла:
без них новую версию придётся ставить начисто.

### Windows
Скачай `Vindica-Setup-….exe` и запусти. Windows может предупредить, что издатель неизвестен:
«Подробнее» → «Выполнить в любом случае». Закрытие окна прячет программу в трей (значок у часов);
выйти — правой кнопкой по значку → «Выйти». Там же выключается запуск вместе с компьютером.
Голосовая заметка на Windows: нажми **Win+H** и говори.

### macOS
В Actions → «Сборка приложений» → **Run workflow** → галочка «Собрать и для macOS».
Первый запуск: правой кнопкой по программе → «Открыть».

## Что где лежит
- `index.html`, `sw.js`, `manifest.webmanifest`, `*.png` — сайт (он же веб-часть приложений)
- `android/` — проект Android (Capacitor), `capacitor.config.json`, `package.json`
- `desktop/` — программа для компьютера (Electron)
- `scripts/prepare-www.js` — копирует сайт внутрь приложений перед сборкой
- `.github/workflows/build.yml` — сборка и выпуск
